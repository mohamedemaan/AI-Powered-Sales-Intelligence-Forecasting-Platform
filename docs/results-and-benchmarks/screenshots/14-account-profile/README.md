# Module Screenshot: User Profile & Account Workspace Settings

**Target Route**: `/profile`  
**Expected Screenshot File**: `14-account-profile.png`  
**Alternative / Additional Files**: `account-settings.png`, `user-profile.png`  
**Description**: Visual display of the authenticated user's account details, Corporate Email, Username, Assigned RBAC Role (Admin / Analyst), Tenant Organization Workspace, Session Token validation, and security credentials.

---

## How to Add Your Screenshot:
1. Open the running frontend (`http://localhost:3000` or deployed URL).
2. Log in and navigate to **User Profile / Account** at `/profile` (or click your user avatar / profile menu in the sidebar).
3. Ensure the account attributes are visible:
   - Full Name & Username
   - Corporate Email
   - Role badge (e.g., `Admin` or `Analyst`)
   - Organization / Multi-Tenant Workspace name
   - Account security & password management settings
4. Capture the screen via `Win + Shift + S`.
5. Save the image file as: `14-account-profile.png`
6. Place the file directly in this folder:
   `docs/results-and-benchmarks/screenshots/14-account-profile/`

Once placed, it will automatically link and render in the [Screenshot Gallery](../README.md) and [Web Application Test Report](../../WEB_APPLICATION_TEST_REPORT.md).
