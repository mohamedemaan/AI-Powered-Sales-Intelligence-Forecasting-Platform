## 3. Step-by-Step Instructions: How to Add Real Screenshots

Follow this step-by-step guide to capture and place application screenshots into the repository.

### Step 1: Open Your Browser & Navigate to the Module
1. Open your browser and go to your running frontend (e.g. `http://localhost:3000` or your Vercel deployment URL).
2. Log in with your credentials to access the dashboard.
3. Click the navigation link corresponding to the module you wish to capture (e.g., **Overview**, **Sales Analytics**, **Forecast Lab**, etc.).

### Step 2: Capture the Full-Screen or Component Screenshot
- **Windows Shortcut**: Press `Win + Shift + S` to open the Windows Snipping Tool. Select "Window Snip" or drag across the application area.
- Alternatively, press `Print Screen` (`PrtScn`) or use browser DevTools (`Ctrl + Shift + P` → *"Capture full size screenshot"*).

### Step 3: Save the Screenshot with the Exact Recommended Filename
Save your screenshot as a `.png` file using the exact standard filename for that module:
- Module 01: `01-overview-dashboard.png`
- Module 02: `02-data-upload.png`
- Module 03: `03-data-cleaning.png`
- Module 04: `04-sales-analytics.png`
- Module 05: `05-forecast-lab.png`
- Module 06: `06-anomaly-detection.png`
- Module 07: `07-scenario-simulation.png`
- Module 08: `08-inventory-intelligence.png`
- Module 09: `09-model-health.png`
- Module 10: `10-gemini-ai-advisor.png`
- Module 11: `11-knowledge-assistant.png`
- Module 12: `12-reports-exports.png`
- Module 13: `13-subscription-audit.png`
- Module 14: `14-account-profile.png`

### Step 4: Paste / Move the Image into its Target Directory
Copy your saved image into the matching subfolder under `docs/results-and-benchmarks/screenshots/`:
- For Module 01 → Place in `docs/results-and-benchmarks/screenshots/01-overview/`
- For Module 02 → Place in `docs/results-and-benchmarks/screenshots/02-data-ingestion/`
- For Module 03 → Place in `docs/results-and-benchmarks/screenshots/03-data-cleaning/`
- ...and so forth for all 13 modules.

### Step 5: Verify & Commit
1. Check that the file paths match the markdown image links above.
2. Push your changes to GitHub:
   ```bash
   git add docs/results-and-benchmarks/screenshots/
   git commit -m "docs: add verified application screenshots for modules"
   git push origin main
   ```
3. When viewing on GitHub, each image will render cleanly in place of the placeholder reference!
